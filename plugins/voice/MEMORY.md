# 客户端记忆（0.6）

记忆文件为 `clients/<deviceId>/memory.json`，文件权限 0600。设备身份、存储和工具均在服务端绑定；设备令牌没有管理 API 权限。新记忆功能不引入额外模型账号、外部数据库或运行时依赖。

## 事实、摘录与上下文

长期事实与聊天上下文分开：事实可跨会话名称和模式使用；dsh 上下文仍按客户端、会话名称、模式和记忆代次独立。记忆 schema v2 包括：

```json
{
  "schemaVersion": 2,
  "revision": 1,
  "updatedAt": 1792915200000,
  "barrier": 0,
  "items": [{
    "id": "uuid",
    "text": "我喜欢咖啡",
    "key": "preference.drink.coffee",
    "kind": "preference",
    "importance": 3,
    "createdAt": 1792915200000,
    "updatedAt": 1792915200000,
    "source": {"actor":"user", "conversationId":"main", "turnId":"uuid"}
  }],
  "events": [],
  "episodes": []
}
```

`kind` 为 profile / preference / fact / event；重要程度 1–5；可选 `expiresAt` 是 Unix 毫秒时间，到期后不再召回。主题键为小写字母、数字及 `. _ : -`，最长 96 字。当前最多 256 条事实、共 64000 字，每条 1000 字。到期事实仍占用存储配额，需管理端整理。

`source` 记录最近一次实际更改的来源（user / assistant / settings / migration）及对话/轮次引用。操作记录最多 128 条，只存操作元数据，不存被替换或删除的原文。相同文本的格式变化不会重复新增；稳定主题键或明确的记录 ID 可更新原事实，保留原 ID 与创建时间。

最近 128 轮成功的 agent 问答存为检索摘录，每轮用户输入最多 480 字、助手回答最多 720 字。取消、出错、旧记忆代次的迟到结果和明显含凭据的内容不进入摘录；纯播报不进入。摘录不是模型生成的总结，也不保证保留末尾信息。

## 自动记录和模型工具

设置 `memoryPolicy`：

- explicit（默认）：规则识别直接的“请记住”“帮我记住”等请求。模型工具仅应在用户明确要求时保存。
- adaptive：额外识别直接陈述的常见偏好，如“我不喝咖啡”“我住在杭州”。条件句、转述、疑问和明显凭据排除。规则覆盖有限，不承诺通用自然语言抽取。
- off：停止自动事实记录、模型新增/更新和对话摘录。保留已有记忆的检索和遗忘能力。管理者仍可手动编辑。

工具 `voice_memory` 按当前 agent 和轮次注册，结束后释放，取消后拒绝使用。只允许 read / remember / forget：

```json
{"operation":"remember","key":"preference.drink.coffee","kind":"preference","text":"我现在不喝咖啡","importance":3}
{"operation":"read","query":"饮品偏好 coffee","limit":12}
{"operation":"forget","id":"当前客户端已有的记录 ID"}
```

`remember` 可带原 `id` 或稳定 `key`；`expiresAt` 可设未来时间或 null 取消到期。不允许自选客户端或存储路径。输入参数由服务器再次校验，模型调用成功之后才能确认保存；规则未识别到并不代表已经写入。

明显的密码/密钥/令牌有后端拒收规则，但模式匹配不能覆盖所有敏感信息。凭据应保存在专门的账号配置中，不应交给记忆。

## 相关检索

检索范围始终为当前客户端。中文双字片段和英文词与事实文本、主题键、问答摘录匹配，按匹配程度、重要程度、资料类型、时间排序。每轮选择有限事实和最多三段相关摘录，并限制注入长度；记忆工具可进一步查询。

这不是向量语义搜索，也不自动扫描升级前所有 dsh 日志。改写较大、没有共同词语的问题可能漏检；问答摘录可能包含旧推测，因此当前事实和人设优先，摘录内容不作为可执行指令。

## 更正和遗忘

更正事实原文、遗忘单条或清空时，事实、检索摘录和记忆屏障在同一个文件中原子写入。使用临时文件、文件 fsync、原子重命名及 Linux 目录 fsync。损坏/未知格式拒绝加载，不会静默清空。

新屏障让下一轮无法自动续接之前的聊天上下文或 UI。此前的上下文归档不再可恢复，旧轮次也不能继续修改记忆或把迟到摘录保存回来。为避免关联旧说法再次进入模型，当前实现会清除该客户端全部检索摘录；其他长期事实保留，其他客户端保留。

遗忘不会删除 dsh 原始日志、宿主文件、部署备份或模型服务商的数据，无法收回当前轮已经输入模型的内容。当前 Shell 仍具宿主全访问权限，因此这里的隔离不构成操作系统沙箱。

## 管理 API

仍需 dsh owner 登录或 adminToken。`GET /clients/:id/memory` 返回全部结构化数据；`POST /clients/:id/memory`：

| operation | 参数 |
|---|---|
| upsert | revision、text，及可选 id/key/kind/importance/expiresAt |
| forget | revision、id |
| clear | revision |
| search | query、可选 limit（1–32） |

写操作的 revision 必须等于当前事实版本，否则 409。摘录新增不改变事实编辑版本；单进程内所有读改写同步执行，不会跨 await 丢失更新。独立多进程同时写同一数据目录不受支持。

兼容 `PUT /clients/:id/memory {text,revision}` 小批量全文替换（最多 8032 字）；新界面使用逐条操作，避免大容量数据超过管理请求限制。旧版事实在读取时适配新模型，首次实际修改时写入 v2，保留 ID 和事实版本；未知新格式拒绝降级读取。
